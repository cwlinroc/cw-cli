# Add Universal Gitignore Rules

The `.gitignore` generation command will now include a universal set of ignore patterns regardless of the selected language flags. This ensures project-agnostic files like draft directories (`docs/draft/`) and local settings (`settings.local.json`) are always excluded from version control.

## Status

accepted

## Context

When generating a `.gitignore` file, developers often have files or folders that they want to ignore regardless of the programming languages they use.
Specifically, `docs/draft/` (which holds scratchpads/draft documentation) and `settings.local.json` (which holds local workspace settings) should always be ignored.
Rather than requiring the user to add these manually, we will include them in a universal ignore block.

## Consequences

- Every `.gitignore` file generated by `cw add gitignore` or `cw touch gitignore` will automatically include a `# Universal` section.
- Reduces the risk of accidentally committing local settings and scratch documentation files.
