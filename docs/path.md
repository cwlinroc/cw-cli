# path

Copy the absolute path of the current working directory to the clipboard.

> **Platform:** Windows and macOS only. Not available on Linux.

## Usage

```
cw path
```

## Arguments

| Argument     | Description                          |
| ------------ | ------------------------------------ |
| _(none)_     | Copy the current working directory   |

## Examples

```sh
cw path
```

## Notes

- The command prints a confirmation message to the terminal after copying the path.
